# PayLedger

监听微信 / 支付宝的付款通知，自动记账的 Android 应用。数据全部保存在本机，**不申请网络权限，不上传任何数据**。

## 功能

- **自动记账**：基于系统通知监听（`NotificationListenerService`）被动捕获付款通知，解析金额与收款方后写入本地数据库，无轮询、无前台服务，后台耗电极小
- **明细页**：今日 / 当月支出汇总，按日分组的支出记录，支持备注与删除
- **历史浏览**：月份选择弹窗自由切换任意历史月份
- **统计页**：年度支出柱状图 + 各月合计，点击跳转对应月份明细
- **防重复**：±3 秒时间窗口去重，避免同一笔支付重复入账

## 隐私与安全

- 未声明 `INTERNET` 权限，应用无法联网，数据仅存于应用私有目录（Room / SQLite）
- 通知文本不写入日志，应用对外仅暴露通知监听这一项系统能力

## 使用

1. 安装 APK 后按引导授权「通知使用权」（设置 → 通知使用权 / 通知读取权限）
2. 国产 ROM 建议允许「自启动」并关闭电池优化，保证后台持续记账
3. 之后正常付款即可，收到付款通知后记录会自动出现在明细页

## 构建

- Android Studio（Gradle 8.10.2 / AGP 8.7.3 / Kotlin 2.0.21 / minSdk 26）直接打开构建
- 或命令行：`./gradlew assembleDebug`
- 单元测试：`./gradlew testDebugUnitTest`

## 已知适配

通知文案因版本或渠道可能不同，debug 构建内置「调试」页可查看最近收到的原始通知，便于调整解析规则。
